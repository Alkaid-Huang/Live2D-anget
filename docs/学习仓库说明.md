# 🚀 交互式项目学习仓库 (Interactive Learning Repo)

> **目标**：通过「文档 + 项目」双轨驱动，在选定课题领域达到可验证的前 2% 水平。

本仓库不是一个静态的资料库，而是一个**动态的修练场**。它基于 `AGENTS.md` 中定义的严苛协议，将 AI 助理（LLM）转化为你的个人私人教练。

---

## 🛠 核心运作模式

本仓库的学习过程分为两个关键阶段，确保你不会在“模糊的目标”或“过难的任务”中迷失。

### 阶段 0：领域建模（规划期）
当你有一个想法（如：做一个芒果病虫害识别系统）但无从下手时：
1.  **背景溯源**：助理会询问你的基础（Python、AI、架构知识等）。
2.  **路线拆解**：助理生成 `00-索引.md`，将大系统拆解为一系列 30-60 分钟可完成的「课题文件夹」。
3.  **对齐目标**：将你的愿望转化为具体的「前 2% 成功标准」。

### 阶段 1：课题闯关（执行期）
每个课题文件夹（如 `01-rbac-auth/`）都包含一套闭环流程：
1.  **核心内容**：阅读 `01-核心内容.md`，掌握模型与概念。
2.  **编码挑战**：在「你的作答区」完成任务。如果你是新手，助理会提供**支架式引导**（填空式编码）。
3.  **自动化验收**：运行 `python test.py`。**测试全绿是提交审阅的唯一前提。**
4.  **知识内化**：在「费曼技巧区」用通俗语言解释核心原理。
5.  **助理审阅**：助理执行人工检查，通过后解锁下一关。

*   **`AGENTS.md`**：仓库的“宪法”。规定了你和助理的互动规则、语言要求及成功标准。
*   **`00-索引.md`**：你的学习地图。包含进度看板、模块路线图以及偏航记录。
*   **`课题文件夹/`**：
    *   `01-核心内容.md`：本课的知识点与任务书。
    *   `test.py` 或 `test.js`：用于自我验证的自动化脚本。
    *   其他源码文件：你真正的实战产出。

## 🚩 偏航与卡顿处理

如果你发现：
*   连续 2 次测试不通过。
*   连续 3 次助理审阅被打回。
*   **或者你觉得“无从下手”。**

**动作**：在对话框或「反馈区」留言。助理会立即触发**「深度复盘模式」**，为你提供多维度类比解释，并可能回退进度，插入更基础的课题帮你打地基。
