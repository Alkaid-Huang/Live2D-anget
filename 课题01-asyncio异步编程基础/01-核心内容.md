## 3. 核心模型：事件循环就像一个"待办事项管理器"

**【类比/解释】** 想象你是一个餐厅服务员：

- 你去厨房下单（发起网络请求），厨房说"等 5 分钟"
- **同步（串行）做法**：你站在厨房门口干等 5 分钟，什么都不做
- **异步做法**：你告诉厨房"好了叫我"，然后去服务其他客人（切换到其他任务），等厨房喊你（事件通知），你再回来取菜

`asyncio` 的事件循环就是这个"服务员"，它管理着一堆待办事项，哪个准备好了就处理哪个。

```
┌─────────────────────────────────────────────┐
│              事件循环（Event Loop）            │
│                                             │
│  ┌──────┐   ┌──────┐   ┌──────┐            │
│  │ 任务A │   │ 任务B │   │ 任务C │   ...      │
│  │ 等待中 │   │ 运行中 │   │ 已完成 │            │
│  └──────┘   └──────┘   └──────┘            │
│       ↑          │                          │
│       └──────────┘                          │
│      A 在等 I/O 时，B 获得执行权               │
└─────────────────────────────────────────────┘
```

**【事实】** 事件循环在单线程中运行，通过协作式调度（cooperative scheduling）而非抢占式调度（preemptive scheduling）来切换任务。这意味着协程必须主动用 `await` 交出控制权，不会被强制中断。

## 4. 关键概念与例子

### 4.1 协程（Coroutine）— `async def`

**【事实】** 协程是 `async def` 定义的函数，调用它不会执行函数体，而是返回一个协程对象。必须用 `await` 或 `asyncio.run()` 才能驱动它执行。

```python
import asyncio

# 定义一个协程
async def say_hello():
    print("你好")
    await asyncio.sleep(1)  # 异步等待，不阻塞其他协程
    print("世界")

# 错误做法：直接调用
# result = say_hello()  # 这只会返回一个协程对象，不会执行！

# 正确做法：用 asyncio.run() 启动
asyncio.run(say_hello())
```

### 4.2 `await` — 交出控制权

`await` 后面必须跟一个"可等待对象"（awaitable）：协程、Task 或 Future。

当执行到 `await xxx` 时，事件循环会暂停当前协程，去执行其他准备好的任务，等 `xxx` 完成后再回来继续。

### 4.3 `asyncio.create_task` — 把协程包装成任务

**【事实】** `create_task` 将协程包装成 Task 并立即提交给事件循环调度。Task 在后台运行，你不需要立刻 `await` 它。

```python
import asyncio

async def download(url, seconds):
    print(f"开始下载 {url}...")
    await asyncio.sleep(seconds)  # 模拟下载耗时
    print(f"下载完成 {url}!")
    return f"{url} 的内容"

async def main():
    # 创建两个并发任务
    task_a = asyncio.create_task(download("A", 2))
    task_b = asyncio.create_task(download("B", 1))
    
    print("任务已创建，等待完成...")
    
    # 等待所有任务完成
    result_a = await task_a
    result_b = await task_b
    
    print(f"结果: {result_a}, {result_b}")

asyncio.run(main())
```

**输出**：
```
任务已创建，等待完成...
开始下载 A...
开始下载 B...
下载完成 B!       ← B 先完成（1 秒），因为 A 还在等
下载完成 A!       ← A 后完成（2 秒）
结果: A 的内容, B 的内容
```

**【类比/解释】** `create_task` 就像把一道菜的单子交给厨房后，你不需要等在厨房门口——厨房会自己处理，你只需要在需要上菜的时候 `await` 取结果。

### 4.4 `asyncio.gather` — 批量等待多个任务

`gather` 同时等待多个任务，返回一个包含所有结果的列表。

```python
results = await asyncio.gather(
    download("A", 2),
    download("B", 1),
    download("C", 1.5),
)
# results = ["A 的内容", "B 的内容", "C 的内容"]
```

### 4.5 `asyncio.TaskGroup` — 结构化并发（Python 3.11+，推荐）

**【事实】** Python 3.11 引入了 `TaskGroup`，它比 `gather` 更安全：如果组内任何一个任务失败，其他任务会自动取消，不会留下"僵尸任务"。[$TRAE_REF](https://m.toutiao.com/group/7633800705274348075)

```python
async def main():
    async with asyncio.TaskGroup() as tg:
        task_a = tg.create_task(download("A", 2))
        task_b = tg.create_task(download("B", 1))
        task_c = tg.create_task(download("C", 1.5))
    # 退出 with 块时自动等待全部任务完成
    # 如果任何一个失败，其他全部自动取消
    
    print(f"全部完成: {task_a.result()}, {task_b.result()}, {task_c.result()}")
```

**【对比】** `gather` vs `TaskGroup`：

| 场景 | `asyncio.gather` | `asyncio.TaskGroup` |
|------|-----------------|---------------------|
| 一个任务失败 | 默认抛出异常，其他任务继续（可能变成僵尸） | 自动取消所有其他任务 |
| 代码结构 | 一次性传入所有协程 | 在 `with` 块内逐个创建 |
| Python 版本 | 3.7+ | 3.11+ |

### 4.6 协程 vs 任务 vs Future — 三者区别

| 概念 | 是什么 | 类比 |
|------|--------|------|
| **协程** (Coroutine) | `async def` 定义的函数，调用返回协程对象 | 菜谱（描述怎么做，但还没做） |
| **任务** (Task) | 协程被 `create_task` 包装后提交给事件循环 | 已下单的菜（厨房正在做） |
| **Future** | 一个"占位符"，代表将来会有结果 | 取餐牌（菜好了会亮灯） |

## 5. 常见坑

### 坑 1：忘记 `await`

```python
async def main():
    download("A", 2)  # ❌ 没 await，协程不会执行！
    # 正确: await download("A", 2)
```

### 坑 2：在协程里用 `time.sleep`

```python
import time

async def main():
    time.sleep(2)  # ❌ 这会阻塞整个事件循环！
    # 正确: await asyncio.sleep(2)
```

### 坑 3：在 `gather` 中混用协程和普通函数

```python
results = await asyncio.gather(
    download("A", 2),  # ✅ 协程
    time.sleep(1),      # ❌ time.sleep 返回 None，不是 awaitable
)
```

### 坑 4：用 `create_task` 但忘记保存引用

```python
async def main():
    asyncio.create_task(download("A", 10))  # ❌ 任务可能被垃圾回收！
    # 正确: task = asyncio.create_task(...)
```
