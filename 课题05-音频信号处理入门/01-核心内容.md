## 3. 核心模型：声音到数字的转换链

### 3.0 概念关系地图（先看这张图，再往下读）

本课的五个核心概念不是孤立散点，而是一条**因果推导链**。理解了这条链，每个参数的选择就不再是"拍脑袋"，而是必然结果：

```
人耳可听频率范围 (20Hz - 20kHz)
        │
        ▼ 奈奎斯特定理：采样率 ≥ 2 × 最高频率
采样率必须够高
        │
        ├──→ CD 音质：2 × 22050 = 44100 Hz（覆盖全人耳）
        └──→ 语音场景：人声主要在 4kHz 以下 → 16000 Hz 足够（Whisper 标准）
        │
        ▼ 采样得到 PCM 数据
PCM：每秒 N 个数字（如 16000 个/秒）
   参数1：采样率（每秒多少点）
   参数2：位深（每个点用多少 bit）
        │
        ▼ 数据量太大（16000 点/秒），直接喂识别模型太慢
        │
        ▼ 提取特征，压缩维度
MFCC：把 16000 个点压缩成 13 个"声音指纹"
   分帧 → 加窗 → FFT → Mel滤波 → 取对数 → DCT
        │
        ▼
喂给 ASR / 情感识别模型
```

**【关键推导】** 为什么 Whisper 用 16000Hz 而不是 44100Hz？不是因为省事，而是：人声主要能量集中在 4kHz 以下 → 奈奎斯特定理要求 ≥ 8kHz → 取 16kHz 留余量。用 44100 纯属浪费算力。**采样率不是越高越好，而是"够用就行"**——这是后续课题06（VAD 也用 16kHz）、课题07（ASR 输入格式）会反复复用的结论。

> 💡 **代码与原理对应表（后续课题会反复用到这些 API）**：
> | 代码 | 对应原理步骤 |
> |------|------------|
> | `sd.rec(samplerate=16000)` | PCM 采样（奈奎斯特定理决定 16000） |
> | `sf.write(subtype='PCM_16')` | 位深 16-bit（每个点用 16bit 存） |
> | `librosa.load(sr=16000)` | 读取 + 自动重采样到 16kHz |
> | `librosa.feature.mfcc(n_mfcc=13)` | 分帧→FFT→Mel→对数→DCT 全流程 |
> | `torch.from_numpy(data).float()` | numpy 转 Tensor（课题06 VAD 用到） |

### 3.1 第一性原理：声音是什么？

**【类比/解释】** 声音是空气分子的振动。当你说话时，声带振动推动空气，空气压力一会儿高一会儿低，形成压力波。麦克风把压力波变成电压信号（模拟信号），声卡把电压信号变成数字数组（数字信号）。

```
声带振动 → 空气压力波 → 麦克风电压 → 声卡采样 → 数字数组
(物理)     (模拟信号)    (模拟电信号)   (ADC)      (PCM数据)
```

### 3.2 PCM：把连续的波切成离散的点

**【类比/解释】** 想象你要记录一根弹簧的振动。你每秒钟拍一张照片，记录弹簧的位置。拍得越快（采样率越高），记录得越精确。如果你每秒只拍 10 张，可能错过弹簧最快的振动；每秒拍 44100 张，连最细微的振动都能捕捉到。

**PCM（Pulse Code Modulation，脉冲编码调制）** 是最常见的数字音频格式。它的核心是两个参数：

| 参数 | 含义 | 典型值 | 影响 |
|------|------|--------|------|
| **采样率**（sample rate） | 每秒采集多少个点 | 16000 / 44100 / 48000 Hz | 越高，能记录的最高频率越高 |
| **位深**（bit depth） | 每个点用多少位存储 | 16-bit / 24-bit / 32-bit | 越高，音量记录越精细 |

```
原始声波（连续）
    │  ╱╲    ╱╲
    │ ╱  ╲  ╱  ╲    ╱
    │╱    ╲╱    ╲__╱
    └──────────────────→ 时间

PCM 采样（离散，每秒采 8 个点）
    │  ●     ●
    │   ●   ● ●
    │    ● ●   ●  ●
    │     ●     ●●
    └──────────────────→ 时间
    每秒 8 个点 = 采样率 8Hz
```

### 3.3 奈奎斯特定理：为什么采样率必须是最高频率的 2 倍？

**【事实】** 奈奎斯特-香农采样定理指出：要从采样信号中无失真地恢复原始信号，采样率必须至少是信号最高频率的 2 倍。人耳可听频率范围是 20Hz - 20000Hz，所以 CD 音质用 44100Hz（> 40000Hz），能覆盖到 22050Hz。[$TRAE_REF](https://en.wikipedia.org/wiki/Nyquist%E2%80%93Shannon_sampling_theorem)

**【类比/解释】** 想象一个旋转的车轮，你每秒拍一张照片。如果轮子每秒转 1 圈，你每秒拍 2 张，能看出它在转。如果轮子每秒转 2 圈，你每秒只拍 1 张，照片上轮子看起来没动——这就是**混叠**（aliasing），高频信号被误认为低频信号。

| 场景 | 采样率 | 能记录的最高频率 | 典型用途 |
|------|--------|----------------|---------|
| 电话 | 8000 Hz | 4000 Hz | 语音通话（听得懂但闷） |
| Whisper ASR | 16000 Hz | 8000 Hz | 语音识别（够用了） |
| CD 音质 | 44100 Hz | 22050 Hz | 音乐欣赏 |
| 专业录音 | 48000 Hz | 24000 Hz | 影视/专业音频 |

### 3.4 MFCC：为什么不用原始波形？

**【类比/解释】** 想象你要认出一个人——你是看他的"原始像素"（每个像素的 RGB 值）快，还是看他的"特征"（脸型、眼距、鼻梁高度）快？显然是特征。语音识别也一样——原始波形有 16000 个点/秒，数据量太大且包含太多无关信息（音量、环境噪声）。MFCC 就是声音的"面部特征"：它把 16000 个点压缩成 13-40 个数字，保留语音的辨识信息。

**MFCC（Mel-Frequency Cepstral Coefficients，梅尔频率倒谱系数）** 的提取过程：

```
原始波形（16000 点/秒）
    │
    ▼ ① 分帧：把长波形切成 20-40ms 的短片段
    │
    ▼ ② 加窗：让每帧两端平滑过渡，减少频谱泄漏
    │
    ▼ ③ FFT：把时域信号转成频域信号（看到各频率的能量）
    │
    ▼ ④ Mel 滤波：按 Mel 刻度分组（人耳对低频敏感、高频迟钝）
    │
    ▼ ⑤ 取对数：模拟人耳对音量的非线性感知
    │
    ▼ ⑥ DCT：去相关，得到最终的 MFCC 系数
    │
最终输出：每帧 13-40 个数字（而不是 16000 个）
```

**【事实】** MFCC 描述了音频信号频谱包络的整体形状，被广泛用于语音情感识别、说话人识别、ASR 等任务。其计算过程包含短时傅里叶变换（STFT）、Mel 刻度映射、对数变换和离散余弦变换（DCT）。[$TRAE_REF](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0291500)

## 4. 关键概念与例子

### 4.1 sounddevice：录制音频

```python
import sounddevice as sd
import numpy as np

# 设置录音参数
fs = 16000          # 采样率 16000Hz（Whisper 标准）
duration = 5        # 录音 5 秒
channels = 1        # 单声道（语音识别用单声道足够）

# 录音：返回 numpy 数组
print("开始录音...")
recording = sd.rec(int(duration * fs), samplerate=fs, channels=channels, dtype='float32')
sd.wait()           # 等待录音完成
print(f"录音完成！数组形状: {recording.shape}")  # (80000, 1) —— 5秒 × 16000/秒
```

**关键方法速查表：**

| 方法 | 作用 | 参数 | 返回值 |
|------|------|------|--------|
| `sd.rec(frames, samplerate, channels, dtype)` | 录音，返回 numpy 数组 | `frames`：采样点数；`samplerate`：采样率；`channels`：声道数；`dtype`：数据类型 | numpy 数组 |
| `sd.wait()` | 等待录音/播放完成 | 无 | `None` |
| `sd.play(data, samplerate)` | 播放音频数组 | `data`：numpy 数组；`samplerate`：采样率 | `None` |
| `sd.query_devices()` | 列出所有音频设备 | 无 | 设备列表 |

**【事实】** `sd.rec()` 返回的数组形状为 `(frames, channels)`。dtype 默认是 `'float32'`，取值范围 -1.0 到 1.0。[$TRAE_REF](https://python-sounddevice.readthedocs.io/en/0.4.1/usage.html)

### 4.2 soundfile：保存和读取 WAV 文件

```python
import soundfile as sf

# 保存为 WAV 文件
sf.write('output.wav', recording, fs)

# 读取 WAV 文件
data, sample_rate = sf.read('output.wav')
print(f"读取到数组形状: {data.shape}, 采样率: {sample_rate}")
```

| 方法 | 作用 | 参数 | 返回值 |
|------|------|------|--------|
| `sf.write(file, data, samplerate, subtype)` | 保存音频为文件 | `file`：文件名；`data`：numpy 数组；`samplerate`：采样率；`subtype`：位深（如 `'PCM_16'`） | 无 |
| `sf.read(file)` | 读取音频文件 | `file`：文件名 | `(data, samplerate)` 元组 |

### 4.3 librosa：提取 MFCC 特征

```python
import librosa

# 读取音频（librosa 会自动重采样到指定采样率）
y, sr = librosa.load('output.wav', sr=16000)

# 提取 MFCC 特征
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)
print(f"MFCC 形状: {mfcc.shape}")  # (13, 帧数) —— 13 个系数 × 若干帧
```

| 方法 | 作用 | 参数 | 返回值 |
|------|------|------|--------|
| `librosa.load(path, sr)` | 读取音频文件 | `path`：文件路径；`sr`：目标采样率（None 则用原始） | `(y, sr)` —— (numpy 数组, 采样率) |
| `librosa.feature.mfcc(y, sr, n_mfcc)` | 提取 MFCC 特征 | `y`：音频数组；`sr`：采样率；`n_mfcc`：MFCC 系数个数 | 2D 数组 `(n_mfcc, 帧数)` |

**【事实】** `librosa.feature.mfcc()` 默认提取 20 个 MFCC 系数。语音识别常用 13 个（前 13 个系数已包含足够的语音辨识信息）。[$TRAE_REF](https://librosa.org/doc/0.10.2/generated/librosa.feature.mfcc.html)

### 4.4 完整流程图

```
麦克风 → sounddevice.rec() → numpy 数组 → soundfile.write() → WAV 文件
                                                          │
                                                          ▼
                                            librosa.load() → numpy 数组
                                                          │
                                                          ▼
                                            librosa.feature.mfcc() → MFCC 特征矩阵
                                                          │
                                                          ▼
                                              (课题11 用于情感识别)
```

## 5. 常见坑

### 坑 1：采样率不匹配

```python
# 用 44100 录音，但 Whisper 需要 16000
recording = sd.rec(int(5 * 44100), samplerate=44100, channels=1)
sf.write('out.wav', recording, 44100)

# Whisper 读取时需要重采样，否则识别质量下降
# librosa.load(sr=16000) 会自动重采样
y, sr = librosa.load('out.wav', sr=16000)  # ✅ 自动重采样到 16000
```

### 坑 2：声道数搞错

```python
# 录音时用双声道
recording = sd.rec(int(5 * 16000), samplerate=16000, channels=2)
# recording.shape = (80000, 2) —— 2D 数组

# librosa.load 默认转单声道
y, sr = librosa.load('out.wav')  # y.shape = (80000,) —— 1D 数组
# 但 soundfile.read 不会自动转
data, sr = sf.read('out.wav')  # data.shape = (80000, 2) —— 还是 2D
```

### 坑 3：dtype 不匹配

```python
# sounddevice 默认 float32（-1.0 到 1.0）
recording = sd.rec(int(5 * 16000), samplerate=16000, channels=1)
# recording.dtype = float32

# soundfile 写入 PCM_16（-32768 到 32767）时，sf.write 会自动转换
sf.write('out.wav', recording, 16000, subtype='PCM_16')  # ✅ 自动转换

# 但如果你手动转 int16，注意范围
recording_int16 = (recording * 32767).astype(np.int16)  # ✅ 正确
```

### 坑 4：录音时没有 wait()

```python
recording = sd.rec(int(5 * 16000), samplerate=16000, channels=1)
# ❌ 没有 sd.wait()，recording 里可能全是 0 或不完整的数据
sf.write('out.wav', recording, 16000)

# ✅ 必须等待录音完成
recording = sd.rec(int(5 * 16000), samplerate=16000, channels=1)
sd.wait()  # 阻塞直到录音完成
sf.write('out.wav', recording, 16000)
```

### 坑 5：MFCC 的帧数不等于采样点数

```python
# 录音 5 秒，16000Hz，数组有 80000 个点
y, sr = librosa.load('out.wav', sr=16000)  # y.shape = (80000,)

# 但 MFCC 的帧数不是 80000
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)
# mfcc.shape = (13, 157) —— 157 帧，不是 80000 帧
# 因为 MFCC 按帧提取，默认每帧 2048 个点，帧移 512 个点
# 帧数 ≈ (80000 - 2048) / 512 + 1 ≈ 153 帧
```
