## 三、怎么运行产品

```bash
cd D:\01_Work\00_Todo\echo-voice-assistant

.\run.bat --mode console                        # 语音对话（默认 half 双工）
.\run.bat --mode agent --text "现在几点？北京天气怎么样？"
.\run.bat --mode mic --seconds 10               # 麦克风诊断：实时 dB / 语音概率
python -m pytest tests -q                       # 52 个 mock 测试
```

产品仓库的 `AGENTS.md` 里写了架构不变量、编码/测试/文档规范与安全红线；
本仓库的 `AGENTS.md` 是教学协议（阶段化学习流程），两者用途不同、互不覆盖。
