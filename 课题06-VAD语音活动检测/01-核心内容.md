### 3.1 第一性原理：为什么需要 VAD？

**【类比/解释】** 想象你在打电话给客服。如果客服把你思考时的沉默、翻资料的声音、背景噪音全都录下来发给识别系统，识别系统会把"呃...嗯..."这些也转成文字，结果满屏废话。VAD 就像一个智能门卫——只在"确实有人在说话"时才开门放行，其他时候关门挡住噪音。

Echo 的管线是这样的：

```
麦克风音频流 → [VAD] → 语音段 → [ASR] → 文字 → [LLM] → 回复 → [TTS] → 语音输出
                ↑
          VAD 是"门卫"
    只放行"有人说话"的片段给 ASR
```

**如果不用 VAD 会怎样？**
- ASR 会把静音识别成乱码或"嗯"
- 浪费算力：Whisper 处理 5 秒静音和处理 5 秒语音耗时一样
- 用户体验差：Echo 会对着空气回复

**【事实】** Open-LLM-VTuber 在音频输入和 ASR 之间有 VAD 环节，用于切分语音段，避免把静音送去识别。silero-vad 是社区广泛使用的轻量级 VAD 模型，MIT 许可证。[$TRAE_REF](https://github.com/snakers4/silero-vad)

### 3.2 VAD 的工作原理

**【类比/解释】** VAD 不是简单地看"音量大不大"。想象一个保安判断"有没有人在说话"——他不只看声音响不响（因为装修噪音也响），还要看声音的"特征"像不像人声。silero-vad 用一个训练好的神经网络，学习了人声和非人声的区别，对每段音频输出一个 0 到 1 的"是人声的概率"。

```
音频片段（30ms）
    │
    ▼
silero-vad 神经网络
    │
    ▼
概率分数（0.0 ~ 1.0）
    │
    ▼
概率 > 阈值？  ──是──→ 标记为"语音"
    │
    否
    │
    ▼
标记为"静音/噪音"
```

### 3.3 核心参数解析

`get_speech_timestamps` 函数有多个参数控制检测行为：

| 参数 | 含义 | 默认值 | 调大的效果 |
|------|------|--------|-----------|
| `threshold` | 语音概率阈值 | 0.5 | 更严格，只有很确定是人声才算 |
| `min_speech_duration_ms` | 最小语音片段长度 | 250ms | 过滤掉太短的杂音（如咳嗽） |
| `min_silence_duration_ms` | 触发"说完了"的最短静音 | 100ms | 需要更长沉默才判定一句话结束 |
| `speech_pad_ms` | 语音段两端填充 | 30ms | 避免把说话开头/结尾切掉 |
| `return_seconds` | 返回秒还是采样点 | False | True 则返回秒数（更直观） |

**【类比/解释】** 想象一个会议记录员：
- `threshold` = 他的"听力灵敏度"，太低会把杂音当说话，太高会漏掉小声说话
- `min_silence_duration_ms` = 他认为"停顿"和"说完了"的区别——停 0.1 秒是换气，停 2 秒是说完一句
- `speech_pad_ms` = 他记录时，每句话前后多留一点缓冲，免得把"啊"字的尾巴切掉

**【事实】** NVIDIA NeMo 文档建议 threshold 取值 0.4-0.7：0.3 过于敏感会误判噪音，0.5 适合大多数场景，0.7 只捕捉清晰语音。[$TRAE_REF](https://docs.nvidia.com/nemo/curator/curate-audio/process-data/quality-filtering/vad)

## 4. 关键概念与例子

### 4.1 silero-vad 的两种调用方式

**方式一：pip 包（推荐，本课使用）**

```python
from silero_vad import load_silero_vad, read_audio, get_speech_timestamps

# 加载模型
model = load_silero_vad()

# 读取音频文件（自动转为 16kHz 单声道）
wav = read_audio('path_to_audio.wav')

# 检测语音段
speech_timestamps = get_speech_timestamps(
    wav,
    model,
    return_seconds=True,  # 返回秒数而不是采样点
)
print(speech_timestamps)
# [{'start': 0.5, 'end': 2.3}, {'start': 3.1, 'end': 5.0}]
```

**方式二：torch.hub（效果一样，代码更长）**

```python
import torch
torch.set_num_threads(1)
model, utils = torch.hub.load(repo_or_dir='snakers4/silero-vad', model='silero_vad')
(get_speech_timestamps, _, read_audio, _, _) = utils
```

**【事实】** silero-vad 6.2.1 是当前最新版（2026-02-24 发布），pip 包方式比 torch.hub 更简洁。两种方式加载的是同一个模型。[$TRAE_REF](https://github.com/snakers4/silero-vad)

### 4.2 read_audio：读取音频文件

```python
from silero_vad import read_audio

# read_audio 会自动把音频重采样到 16kHz 单声道
wav = read_audio('audio.wav')
# wav 是一个 torch.Tensor，1D，值域 -1.0 到 1.0
print(f"音频长度: {len(wav)} 个采样点")
print(f"时长: {len(wav) / 16000:.1f} 秒")
```

| 方法 | 作用 | 参数 | 返回值 |
|------|------|------|--------|
| `read_audio(path)` | 读取音频文件，自动转 16kHz | `path`：文件路径 | `torch.Tensor`，1D |

**注意**：`read_audio` 返回的是 `torch.Tensor`，不是 numpy 数组。但你可以用 `.numpy()` 转换。

### 4.3 get_speech_timestamps：检测语音段

```python
from silero_vad import get_speech_timestamps

# 基础用法
speech_ts = get_speech_timestamps(wav, model, return_seconds=True)
# [{'start': 0.5, 'end': 2.3}, {'start': 3.1, 'end': 5.0}]

# 带参数调优
speech_ts = get_speech_timestamps(
    wav,
    model,
    threshold=0.5,                    # 语音概率阈值
    min_speech_duration_ms=250,       # 最短语音片段 250ms
    max_speech_duration_s=float('inf'), # 最长语音片段（不限）
    min_silence_duration_ms=100,      # 最短静音间隔 100ms
    speech_pad_ms=30,                 # 语音段两端填充 30ms
    return_seconds=True,              # 返回秒数
)
```

| 方法 | 作用 | 关键参数 | 返回值 |
|------|------|---------|--------|
| `get_speech_timestamps(wav, model, ...)` | 检测语音段 | `threshold`、`min_silence_duration_ms`、`return_seconds` | `list[dict]`，每个 dict 有 `start` 和 `end` |

### 4.4 从音频中切分语音段

检测到时间戳后，需要从原始音频中切出对应片段：

```python
import torch

# 假设 return_seconds=False（默认，返回采样点）
speech_ts = get_speech_timestamps(wav, model)  # 返回采样点
# [{'start': 8000, 'end': 36800}, {'start': 49600, 'end': 80000}]

# 切分语音段
for ts in speech_ts:
    chunk = wav[ts['start']:ts['end']]  # 用切片取出一段
    print(f"片段: {ts['start']}-{ts['end']}，长度 {len(chunk)} 点")
```

**关键**：如果 `return_seconds=True`，返回的是秒数，不能直接用于数组切片——需要先乘以采样率转成采样点。

## 5. 常见坑

### 坑 1：return_seconds=True 时不能直接切片

```python
# return_seconds=True 返回秒数
speech_ts = get_speech_timestamps(wav, model, return_seconds=True)
# [{'start': 0.5, 'end': 2.3}]

# ❌ 不能直接用秒数切片
chunk = wav[0.5:2.3]  # 错误！数组索引必须是整数

# ✅ 方案一：用 return_seconds=False（默认），直接返回采样点
speech_ts = get_speech_timestamps(wav, model)
chunk = wav[speech_ts[0]['start']:speech_ts[0]['end']]

# ✅ 方案二：秒数 × 采样率 转成采样点
sr = 16000
start_sample = int(speech_ts[0]['start'] * sr)
end_sample = int(speech_ts[0]['end'] * sr)
chunk = wav[start_sample:end_sample]
```

### 坑 2：threshold 设得太低或太高

```python
# threshold=0.3：太敏感，把背景噪音也当成语音
speech_ts = get_speech_timestamps(wav, model, threshold=0.3)
# 可能返回一堆很短的片段（都是噪音）

# threshold=0.9：太严格，漏掉小声说话
speech_ts = get_speech_timestamps(wav, model, threshold=0.9)
# 可能返回空列表，明明有人说话却检测不到

# ✅ 一般用默认 0.5，有噪音时调到 0.6-0.7
```

### 坑 3：min_silence_duration_ms 设得太短

```python
# min_silence_duration_ms=50：停 50ms 就判定"说完了"
# 用户说话时正常的换气停顿（200-300ms）会被误判为"一句话结束"
# 结果：一句话被切成好几个碎片

# ✅ Echo 用 500-1000ms，允许用户换气停顿
speech_ts = get_speech_timestamps(
    wav, model,
    min_silence_duration_ms=500,  # 停 0.5 秒才算"说完了"
)
```

### 坑 4：忘记模型是全局加载的

```python
# ❌ 每次调用都加载模型（很慢）
def detect(audio_file):
    model = load_silero_vad()  # 每次都加载！
    wav = read_audio(audio_file)
    return get_speech_timestamps(wav, model)

# ✅ 模型只加载一次，复用
_model = None
def get_model():
    global _model
    if _model is None:
        _model = load_silero_vad()
    return _model

def detect(audio_file):
    wav = read_audio(audio_file)
    return get_speech_timestamps(wav, get_model())
```

